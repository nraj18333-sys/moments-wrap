# MOMENTS WRAP App

Starter Flutter application for:
Flowers | Cake | Decor | Gifts | Hampers

Included:
- Home screen using the supplied MOMENTS WRAP logo
- Product catalogue
- Categories
- Add to cart
- Checkout flow (demo)
- Orders
- Admin Add Product screen
- Pink/black/white brand styling
